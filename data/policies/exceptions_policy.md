# Исключения и согласования

## Mobility exception
Для сотрудников категории mobility с требованием wheelchair_access допускаются исключения по времени вылета.
Ночной вылет может быть разрешен без дополнительного согласования, если это снижает число пересадок.

## Прозрачность решения
Любое исключение должно быть объяснено ссылкой на нормативный источник.
