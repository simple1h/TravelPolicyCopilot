# Политика транспорта

## Класс обслуживания
Для категории standard допустим класс economy.
Для категории regional допустим класс economy.
Для категории manager допустим класс business.
Для категории special_budget допустим класс business.
Для категории mobility допустим класс premium_economy или business.

## Ночные вылеты
Вылеты в ночное время с 23:00 до 06:00 требуют дополнительного согласования.
